# Code of Conduct

## Our pledge

We want this project to be a place where anyone can ask a basic robotics
question without being made to feel stupid, and where disagreement about a
controller or a CAD tolerance stays about the work.

## Expected behaviour

- Be direct about technical problems and generous about the person raising them.
- Assume the other person has context you do not.
- Give reproductions, measurements or references when you disagree.
- Respect that some contributors cannot test hardware, and that some can.
- Accept a maintainer's decision to keep scope small.

## Unacceptable behaviour

- Harassment, insults, sexualised attention, or comments about a person's
  identity, appearance or experience level.
- Publishing private information or credentials.
- Dismissing a report of a problem because you cannot reproduce it.
- Sustained disruption of issues, reviews or discussions.

## Scope

This applies in repository spaces (issues, pull requests, discussions) and when
representing the project elsewhere.

## Enforcement

Report problems to the maintainer through a private channel listed on the
maintainer's GitHub profile, or open an issue asking for a private contact if no
channel is public. Reports are handled confidentially. Maintainers may warn,
remove content, or block accounts. A maintainer involved in a report recuses
themselves.
